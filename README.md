# Portofolio Siti Nur Hamidah

**Portofolio UI/UX Designer, Sistem Informasi, dan Content Creator**

Website portofolio personal yang menampilkan profil, keahlian, pengalaman, pendidikan, proyek, pengalaman organisasi, dan sertifikat Siti Nur Hamidah.

</div>

## Tentang Proyek

Portofolio ini dibuat sebagai halaman personal untuk memperkenalkan latar belakang Siti Nur Hamidah, lulusan S1 Sistem Informasi Universitas Negeri Surabaya dengan minat pada UI/UX Design dan Social Media Specialist.

Proyek ini juga menyoroti pengalaman merancang solusi digital yang intuitif, fungsional, inklusif, dan berpusat pada kebutuhan pengguna. Salah satu fokus utama yang ditampilkan adalah tugas akhir **LearnMath**, yaitu perancangan antarmuka pembelajaran matematika untuk siswa tunarungu menggunakan metode User-Centered Design dan prinsip WCAG 2.2.

## Fitur

- Navigasi sticky dengan menu responsif untuk perangkat mobile
- Section profil dan ringkasan pencapaian
- Daftar keahlian teknis, tools desain, pengolahan data, dan kemampuan interpersonal
- Timeline pengalaman kerja dan organisasi
- Informasi pendidikan dan IPK
- Galeri ringkasan enam proyek desain, website, dan basis data
- Daftar sertifikat kompetensi dan organisasi
- Tombol kontak melalui email, telepon, dan Instagram
- Animasi reveal saat konten masuk ke viewport

## Proyek yang Ditampilkan

1. **LearnMath** — Desain UI/UX pembelajaran matematika untuk siswa tunarungu
2. **SIRASA** — Sistem Informasi Risiko dan Aset
3. **Aplikasi Mobile Ciputra Hospital Surabaya** — Prototipe aplikasi mobile interaktif
4. **Website & Database I-Learning SIAKAD** — Implementasi basis data akademik
5. **Website Perkebunan Semoga Sukses** — Desain website menggunakan Wix.com
6. **Database Pembelian Tiket Kereta Api** — Perancangan tabel dan relasi menggunakan MS Access

## Teknologi dan Tools

- **Frontend:** HTML, CSS, JavaScript, Bootstrap
- **UI/UX dan konten:** Figma, Canva, Adobe Illustrator, Wix.com, CapCut
- **Basis data:** SQL, PostgreSQL, phpMyAdmin, MS Access
- **Pendukung:** XAMPP, Visual Studio Code
- **Font:** Fraunces, Plus Jakarta Sans, dan JetBrains Mono melalui Google Fonts

## Cara Menjalankan

Proyek ini merupakan website statis sehingga tidak memerlukan proses instalasi atau build.

1. Clone atau unduh repository ini.
2. Buka file [`Portofolio_SitiNurHamidah.html`](Portofolio_SitiNurHamidah.html) di browser.

Untuk pengalaman pengembangan yang lebih nyaman, file juga dapat dijalankan menggunakan ekstensi **Live Server** di Visual Studio Code.
